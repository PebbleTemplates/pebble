# BREAKING CHANGES
- default to allowlist method access validation.

Add a configurable allowlist for method access and make it the default. Allow common Java types and Pebble's build-in template objects, and update Spring integration and migration documentation

Methods on application classes must be explicitly allowed. Configure BlacklistMethodAccessValidator or NoOpMethodAccessValidator to restore the previous behavior

A new spring-boot property `pebble.allowPackages` is added to configure the allowlist for method access validation. It is a comma-separated list of package names. All public methods of classes in these packages and sub-packages will be allowed.

Please consult the documentation for more details: [Allowlist mode](https://pebbletemplates.io/docs/guide/installation/#allowlist-mode) or for spring-boot integration: [Spring Boot Integration](https://pebbletemplates.io/docs/guide/spring-boot-integration/#method-access-validation)
